# screend

**맥에서 나는 소리를 기본 화면 녹화에 스테레오 그대로 넣어주는 도구. 오디오 설정은 하나도 안 건드린다.**

[English](README.md)

---

macOS 기본 녹화(`Cmd+Shift+5`, QuickTime)는 마이크만 받는다. 유튜브 소리, 게임 소리,
통화 소리, DAW 출력 같은 "맥 내부에서 나는 소리"는 원래 녹화가 안 된다.

`screend` 는 **Core Audio process tap** 을 평범한 입력 장치로 노출시켜서 이 문제를 푼다.
녹화기의 마이크 메뉴에서 이 장치를 고르면 시스템 소리가 스테레오로 녹화된다.

```bash
brew install redsterx9/tap/screend
brew services start screend
```

이후 `Cmd+Shift+5` → **옵션** → **마이크** → **"Screen Recording Audio"** → 녹화.
한 번 골라두면 macOS 가 기억한다.

<details>
<summary>Homebrew 없이 설치</summary>

```bash
git clone https://github.com/redsterx9/mac-screen-audio
cd mac-screen-audio
./install.sh
```

`install.sh` 는 빌드해서 `~/.local/bin` 에 넣고 자체 로그인 에이전트를 등록한다.
</details>

## 오디오 설정을 안 건드린다

이게 핵심이다. 흔한 BlackHole 방법이 세팅을 망치는 이유는 BlackHole 자체가 아니라
**"다중 출력 장치를 만들어 시스템 출력으로 바꿔라"** 는 단계다. 출력 장치가 바뀌는 순간
인터페이스 라우팅이 틀어지고, 작업할 때마다 되돌려야 한다.

탭은 이미 재생 중인 소리를 지나가면서 복사만 한다. 그래서:

|                          | screend | BlackHole + 다중 출력 |
| ------------------------ | ------- | --------------------- |
| 기본 출력 장치를 바꾸나  | 아니오  | **예**                |
| 기본 입력 장치를 바꾸나  | 아니오  | 아니오                |
| 오디오 인터페이스를 건드나 | 아니오 | **예**                |
| 드라이버 설치가 필요한가 | 아니오  | **예**                |
| 관리자 암호가 필요한가   | 아니오  | **예**                |
| 소리는 계속 들리나       | 예      | 예                    |
| 스테레오 L/R 유지        | 예      | 예                    |

`screend off` 하면 장치가 사라지고 되돌릴 설정이 남지 않는다.
`screend status` 로 기본 장치가 그대로인지 언제든 확인할 수 있다.

## 로직(DAW) 녹음

된다. 로직이 오디오 인터페이스로 출력하고 screend 는 아니어도 상관없다.

탭은 특정 장치가 아니라 전역 프로세스 탭이라, 출력 경로가 아니라 앱을 따라가야 한다.
다만 이건 "확인됨"이 아니라 "그럴 것으로 예상됨"으로 봐야 한다. 이걸 증명하려던 측정이
별도 출력 장치로 보낸 톤과 기본 출력으로 흘러간 톤을 구분하지 못해서 다시 측정 중이다.

본인 장비에서 10초면 확인된다 — `screend monitor` 켜고 로직에서 재생을 걸어 미터를 보면 된다.

한 가지 주의: 탭이 잡는 건 DAW 의 **최종 출력**, 마스터 페이더 아래 신호다. 마스터를 줄이면
녹음도 같이 줄어든다. 제대로 된 믹스다운은 DAW 에서 바운스하는 게 맞고, 이건 화면 녹화에
넣을 참고용 오디오 용도다.

## 스테레오

L/R 이 분리된 채로 유지된다. 왼쪽 1kHz / 오른쪽 3kHz 를 재생해서 녹화하면 각 채널에 해당
주파수만 잡히고 반대 채널은 −86dB 아래로 떨어진다. 약 **72dB 채널 분리**.
결과 파일은 `2 ch, 48000 Hz, Stereo (L R)`.

## 명령어

| 명령 | 하는 일 |
| --- | --- |
| `screend on` | 장치 켜고 대기 (Ctrl-C 로 종료) |
| `screend off` | 남은 장치 정리 |
| `screend status` | 상태 + 오디오 기본 장치 확인 |
| `screend check` | 채널별로 소리가 들어오는지 실제 측정 |
| `screend monitor` | 실시간 L/R 레벨 미터 |
| `screend list` | 입력/출력 장치와 UID 목록 |
| `screend permission` | 화면 및 시스템 오디오 녹음 권한 확인 / 요청 |
| `screend install` / `uninstall` | 로그인 에이전트 등록 / 해제 |
| `screend version` | 버전 출력 |
| `screend tone` | 진단용 테스트 톤 (`--device` `--left` `--right` `--amp`) |

## 마이크를 같이 넣기

`screend on --mic` (또는 `./install.sh --mic`) 로 마이크를 같은 장치에 합칠 수 있다.

기본 녹화기는 입력 장치를 **하나만** 받기 때문에 둘은 **한 트랙에 섞여서** 들어가고,
나중에 따로 볼륨을 조절할 수는 없다. 마이크가 너무 크면 `screend check` 가 경고한다.
시스템 설정 → 사운드 → 입력에서 낮추면 된다.

## 동작 구조

`screend on` 은 두 가지를 만든다.

1. 모든 앱의 재생 오디오를 스테레오로 복사하는 **process tap**. `muteBehavior = .unmuted`
   라서 소리는 평소대로 스피커/인터페이스로 계속 나간다.
2. 탭을 입력 채널로 노출시키는 **집계 장치** "Screen Recording Audio". 공개 장치라서
   `screencapture`, QuickTime, `Cmd+Shift+5` 툴바 모두에서 보인다.

집계 장치의 클럭은 **내장 스피커**에서 가져온다. 오디오 인터페이스는 세션 중에 빠질 수
있고, 굳이 집계 장치에 끌어들일 이유도 없다.

탭은 만든 프로세스가 죽으면 같이 사라진다. 그래서 `screend on` 은 상주하고,
`screend install` 이 이걸 로그인 에이전트로 등록한다.

## 검증 기록

이 문서의 주장은 전부 실측한 것이다.

- **마이크 경로가 아님.** 스피커 볼륨 0(방에서 아무 소리도 안 나는 상태)에서 1kHz 톤이
  −12.2dB 로 녹음됨. 볼륨 75 일 때와 동일.
- **스테레오 분리.** L 에만 톤 → R 은 −240dB(완전 무음). L=1kHz/R=3kHz → 각 채널에 해당
  주파수만, 반대 채널은 −86dB 아래.
- **`screencapture -G` 가 지정 장치를 실제로 씀.** 없는 UID 는 에러, 아무것도 안 꽂힌
  인터페이스는 −71dB 무음.
- **44.1kHz 소스도 음정이 안 틀어짐.** 집계 장치 클럭이 48kHz라 44.1kHz 소스는 SRC 를 탄다.
  44.1kHz 1kHz 톤이 정확히 1kHz 로, 48kHz 소스와 같은 레벨로 녹음됨. 변환이 잘못됐다면
  나왔을 918Hz 에는 아무것도 없음.
- **설정 무변동**: 세션 전/중/후 기본 장치 모두 그대로.
- 최종 녹화 파일: `2 ch, 48000 Hz, Stereo (L R)`, 클리핑 0 샘플.

## 권한

screend 는 **화면 및 시스템 오디오 녹음** 권한이 필요하다. 선택이 아니고, 없으면 조용히
실패한다 — 권한 없이 만든 Core Audio 탭도 생성은 성공하고 버퍼도 계속 넘어온다.
그 버퍼가 전부 무음일 뿐이고, 어떤 API 도 에러를 알려주지 않는다.

`screend status` 와 `screend check` 가 권한 상태를 명시해서 무음의 원인을 알려준다. 부여하려면:

```bash
screend permission
```

macOS 는 처음 한 번만 대화상자를 띄운다. 그 뒤로는 시스템 설정 → 개인정보 보호 및 보안 →
화면 및 시스템 오디오 녹음 에서 직접 켜고 screend 를 재시작해야 한다.

## 요구 사항

macOS 14.2 이상 (Core Audio process tap), Xcode 커맨드라인 도구.

## 참고

- 첫 실행 때 화면 녹화 / 마이크 권한을 물어볼 수 있다.
- `screend` 는 어떤 오디오 장치 속성에도 쓰기를 하지 않는다. 읽기만 하고, 자기 탭과
  집계 장치만 만들었다 지운다.
